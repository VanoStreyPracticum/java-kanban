# 📋 Java-Kanban: Трекер задач со специализированными структурами данных

Бэкенд системы управления задачами, эпиками и подзадачами, реализованный на **чистой Java 21** без использования сторонних веб- и ORM-фреймворков.

---

## 🎯 Ключевые архитектурные особенности

### 1. Кастомный менеджер истории с удалением за $O(1)$ (`InMemoryHistoryManager`)
В отличие от стандартного `java.util.LinkedList`, где поиск удаляемого узла по значению требует обхода всего списка за $O(N)$, здесь реализована специализированная структура данных:
* **Собственный двусвязный список:** внутренний статический класс `Node<Task>` с прямыми ссылками `prev` и `next`.
* **Хеш-таблица узлов:** `Map<Integer, Node<Task>>` связывает идентификатор задачи с её физическим узлом в памяти JVM.
* **Результат:** добавление в конец истории и удаление задачи из любой позиции списка (голова, середина, хвост) выполняются строго за константное время **$O(1)$** без дубликатов.

### 2. Встроенный REST HTTP-сервер на стандартной библиотеке
* Сервер реализован на базе низкоуровневого `com.sun.net.httpserver.HttpServer`.
* Обработка REST-эндпоинтов (`/tasks`, `/epics`, `/subtasks`, `/history`, `/prioritized`).
* Маршрутизация HTTP-методов (GET, POST, DELETE), парсинг query-параметров и сериализация в JSON с помощью Gson с кастомными адаптерами для `Duration` и `LocalDateTime`.
* Корректный маппинг HTTP статус-кодов (200 OK, 201 Created, 400 Bad Request, 404 Not Found, 406 Not Acceptable).

### 3. Доменная модель и валидация пересечений
* Иерархия задач: базовая `Task`, составной `Epic` и зависимая `Subtask`.
* Автоматический пересчёт статуса и временных рамок эпика на основе входящих подзадач.
* Приоритетный список задач на базе `TreeSet` с сортировкой по времени начала (`startTime`).
* Алгоритм валидации временных интервалов: предотвращение наложения времени выполнения задач при создании и обновлении.

## 🧪 Тестирование

Бизнес-логика и краевые случаи покрыты исчерпывающим набором Unit-тестов на **JUnit 5**:
* Тестирование `InMemoryHistoryManager`:
  * Добавление задач и удаление дубликатов.
  * Удаление из начала (головы), середины и конца (хвоста) истории.
  * Работа с пустой историей.
* Тестирование расчёта статусов эпиков (все NEW, все DONE, NEW + DONE, IN_PROGRESS).
* Тестирование валидации пересечения интервалов выполнения задач.
* Интеграционные тесты обработчиков HTTP-сервера с реальными сетевыми запросами.

## 💻 Стек технологий

* **Язык:** Java 21 (Pure Core)
* **Структуры данных:** Кастомный DoublyLinkedList, HashMap, TreeSet
* **Сеть и API:** `com.sun.net.httpserver.HttpServer`, RESTful API
* **Сериализация:** Google Gson (с кастомными TypeAdapter)
* **Тестирование:** JUnit 5
